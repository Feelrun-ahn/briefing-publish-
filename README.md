## ⚠️ 서버도 다시 배포해야 합니다

```bash
cd server
wrangler deploy
```

캐시 판번호를 `v2` 로 올려 **옛 캐시를 버리게 했습니다.**
이걸 안 하면 방학 때 저장된 답이 계속 나옵니다.

## 무엇이 문제였나

**학년도·학기를 잘못 보내고 있었습니다.**

8월 21일을 코드가 `1학기` 로 계산했는데, 개학했으면 **2학기** 입니다.
그래서 이번 주 조회가 빈손으로 오고, 8주를 거슬러 올라가다
방학 전 자료(`07/20 주`)를 집어왔습니다.

`여름방학` 이라는 과목명은 지어낸 게 아니라 **나이스에 실제로 그렇게 등록된 값** 입니다.

## 어떻게 고쳤나

**① 학년도·학기를 보내지 않습니다.**
나이스는 날짜 범위(`TI_FROM_YMD` ~ `TI_TO_YMD`)만으로 알아서 찾아 줍니다.
학기를 넘기면 학기가 바뀌는 시기에 오히려 빈손으로 옵니다.

**② 방학·휴업일은 수업으로 치지 않습니다.**

```js
function isNoClass(s){
  return /방학|휴업|휴일|재량|개교기념|연휴|자율화/.test(s);
}
```

이런 값만 있는 주는 건너뛰고 계속 찾습니다.
끝까지 없으면 **"시간표를 찾지 못했습니다"** 라고만 알립니다.

**③ 거슬러 보는 범위를 8주 → 6주로 줄였습니다.**
너무 오래된 자료를 가져오는 것보다 없다고 하는 편이 낫습니다.

## 절대 어기면 안 되는 규칙

- 나이스 조회에 `AY`·`SEM` 을 넘기지 말 것 (날짜만으로)
- 위치는 `Geo.set()` 으로만
- `innerHTML =` 대신 `setHTML()`
- body 에 `overflow-x:hidden` 금지
- 목록 `max-height` · `line-clamp` 금지
- 1초 주기에서 `paint()` 금지 → `paintTick()`
- 오류 문구에 추측을 넣지 말 것

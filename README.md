## 카드 배치 (v25)

설정 → 카드 구성의 **자동 배치 / 직접 조절** 토글.
직접 조절을 누르면 설정이 닫히고 **편집 모드**로 들어갑니다
(카드가 살짝 흔들리고 점선 테두리가 생김).
카드를 끌어 옮기고 **완료**를 누르면 저장됩니다. 폰은 1열, 태블릿은 3열.
평소에도 카드 제목을 길게(0.3초) 누르면 옮길 수 있습니다. `js/drag.js`

## 하루의 기준

`dayOff()` — 밤에 날씨·운세·야구가 내일 것으로 바뀝니다.
설정 → 시간의 **내일 정보로 바뀌는 시각**에서 조절합니다.

- `auto`(기본) — 취침 2시간 전
- `18`~`23` — 지정한 시각부터
- `off` — 바꾸지 않음 (항상 오늘)

자정을 넘기면 그 '내일'이 곧 오늘이므로 다시 오늘 것을 봅니다.
도움말 FAQ 5번에 같은 설명이 있습니다.

## 시간 사용 여부

기상·외출·취침 각각 **사용** 스위치. 끄면 헤더의 남은 시간 표시가 사라집니다.
(예전 "사용 안 함" 체크박스는 뜻이 반대로 읽혀 스위치로 바꿨습니다.)

## 절대 규칙 — 내용을 자르지 않는다

목록 `max-height` 없음, `line-clamp` 없음, `.card{overflow:visible}`.
넘치면 페이지가 아래로 스크롤됩니다. 새 카드에 높이 제한을 넣지 마세요.

## 입력 안정성

`typing()` 중에는 `paint`·`fitStage`·`rebalance`·주기 갱신 모두 정지.
`refit()`은 폭이 24px 이상 바뀐 경우에만 (키보드 높이 변화 무시).
설정 입력은 `bindLiveSave()`로 바꾸는 즉시 저장됩니다.
